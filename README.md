- [x] Utilisation de MongoDB
- [x] Integration de Mongoose
- [x] En-têtes de sécurité
- [x] Index avvancé pour MongoDB
- [x] Configuration CORS

- [x] Validation globale
- [x] Persistance

## Démarrage de MongoDB

